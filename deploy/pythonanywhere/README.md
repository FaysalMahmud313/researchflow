# ResearchFlow: ready-to-run build

This branch is generated by the **Publish** workflow from `main`. Do not edit it by hand.
It holds everything a host needs to run ResearchFlow as one process:

| Path | What it is |
| --- | --- |
| `app/`, `wsgi.py` | The backend (FastAPI) and its WSGI entry point |
| `web/` | The web app, already built |
| `requirements.txt` | Python packages |
| `scripts/admin.py` | List users, reset a password, verify an email |
| `setup.sh`, `update.sh`, `backup.sh` | PythonAnywhere helpers |

Step-by-step instructions are in `docs/DEPLOYMENT.md` on the `main` branch.
